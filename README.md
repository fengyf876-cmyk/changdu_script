## 在篡改猴中使用

1. 在浏览器安装篡改猴扩展。
2. 打开需要的 `.txt` 文件，复制完整内容，包括开头的用户脚本元信息。
3. 在篡改猴中选择“添加新脚本”，用复制的内容替换默认示例，并保存。
4. 打开脚本匹配的网站，按照页面中脚本提供的按钮或面板操作。

需要登录的平台，应先在浏览器中登录对应账号。

## 日常保存版本

如果在篡改猴编辑器中修改脚本，将最新完整代码复制回本地对应文件并保存。Git 管理本文件夹中的文件，不会自动读取篡改猴编辑器里的修改。

在 PowerShell 中执行：

```powershell
Set-Location -LiteralPath 'D:\changdu\数据脚本'
git status
git diff
```

检查修改后，保存一个版本：

```powershell
git add .
git commit -m "修复某平台抓取问题"
```

说明文字可以按实际修改替换。若没有文件改动，则不需要再次提交。

查看历史版本：

```powershell
git log --oneline
```

## GitHub 同步

对应仓库：https://github.com/fengyf876-cmyk/fyf

本地提交完成后，执行：

```powershell
Set-Location -LiteralPath 'D:\changdu\数据脚本'

```

首次上传需要完成 GitHub 身份验证。只有成功上传的提交，才会出现在 GitHub 上。

## 文件保存范围

`.gitignore` 默认排除常见的登录凭据文件、导出数据目录、Excel/CSV 文件、日志与缓存。脚本中的登录凭据应通过浏览器会话或本地配置获取，避免直接写入源代码。

Git 只能恢复已提交的版本；GitHub 只能保存已成功上传的提交。
